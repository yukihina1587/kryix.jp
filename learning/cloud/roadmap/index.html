ガイドCOURSE GUIDE

この教材で学ぶこと 共通基礎から三社のクラウド、サービス比較、その他のクラウドへ進む6段階を確認します。

クラウド学習ロードマップ

改訂日: 2026-09-05

概要

クラウドの共通原理を押さえ、AWS、Azure、GCPをそれぞれ学び、比較できるようになってからCloudflare・ニフクラなどへ広げる。 目標はサービス名を挙げることに加え、要件を受けて構成・権限・障害対応・費用を説明できること。

「基礎知識の習得 → 演習による定着 → 設計・運用への応用」の順で学ぶ。 資格取得済みの項目も演習で確認し、説明できる項目は速習、説明できない項目は本文へ戻る。

順序と完了条件

段階 教材 残す成果物 次へ進む条件
1. 共通基礎 クラウド全般 ベンダー名なしの構成図、責任分界表、RTO/RPO 通信・データ・障害・費用の流れを説明できる
2. AWS 基礎から設計・運用へ AWS構成図、権限表、監視・復旧手順 IAM/VPC/データ/監視の設計理由を説明できる
3. Azure 基礎から設計・運用へ Azure構成図、管理階層、RBAC割り当て表 認証・権限・リソース管理の違いを説明できる
4. GCP 基礎から設計・運用へ GCP構成図、IAM表、ネットワークのスコープ表 プロジェクトとVPCの境界、実行主体を説明できる
5. 横断比較 類似サービスと設計の違い 三社比較表、移植時の変更点 同等の目的と異なる仕様を区別できる
6. その他 その他のクラウド Cloudflare/ニフクラを含む選定メモ 組み合わせる理由と運用負担を説明できる

任意の設計演習で使う架空の題材

理解した概念を比較したい場合の例題として、架空の「学習記録アプリ」を使う。実在の業務やシステムを表すものではなく、このアプリの開発が学習の目的ではない。利用者がログインし、教材を読み、学習進捗を保存する。

  • 平常時の利用者は100人、研修開始時にアクセスが集中する。
  • 教材ファイルと進捗データを分けて保存する。教材は利用者だけが閲覧できる。
  • アプリケーションはHTTPSで利用する。DBをインターネットに直接公開しない。
  • 学習上の仮定として、月間可用性目標99.9%、RTO 4時間、RPO 24時間とする。
  • 単一ゾーン障害と誤削除に備える。リージョン全体の障害は別途、追加要件として評価する。
  • まず机上で設計する。実習環境は合成データを使い、予算・利用時間・片付け対象を事前に決める。

これらは実案件の保証値ではない。章を進めるときは要件を変えず、構成や運用の違いを比較する。 可用性目標とRTOは同じ尺度ではなく、4時間の停止は月間99.9%の停止許容量を超え得る。

一つずつ一緒に進める方法

  1. 各章を小見出し一つずつ読む。最初は共通基礎の「クラウドとは何か」。
  2. 自分の言葉で2〜3分説明する。既知の項目でも責任や失敗時の挙動まで説明する。
  3. 共通題材に当てはめ、図・表・判断理由を残す。
  4. 章末問題に解答してから解答例を読む。別案でも要件を満たし、理由が説明できればよい。
  5. 実環境で確認したい疑問を整理し、次のハンズオンを決める。

読む時間は固定しない。SAA既習の知識量と、構築・復旧を自力でできるかは別々に判定する。

AWSで深める順序

AWS学習コース総合案内から、基礎・上級・開発・運用・DevOps・セキュリティ・営業・企画の8経路へ進めます。227項目の講座・実習・参照指示と元リンクを掲載しています。

導入章のA1〜A6 → 設計・運用 → コンテナ → サーバーレス → DB。 その後、担当業務に応じてネットワーク、アプリケーション、オペレーション、DevOps、セキュリティを深める。 今回の入口教材は各領域の共通土台まで扱う。専門領域ごとの詳細ハンズオンは一つずつ追加する。

演習の評価基準

各観点を0〜2点で自己評価する。0は説明できない、1は資料を見れば説明できる、2は別案と比較して説明できる。

観点 見ること
要件との対応 なぜその構成で要求を満たせるのか
通信と権限 誰がどの経路で何を操作できるか
障害と復旧 何を検知し、どのデータからどう戻すか
費用と運用 何に課金され、誰が日常運用するか
根拠 仮定と公式仕様を分け、未確認点を残したか

8点以上かつ「通信と権限」「障害と復旧」に0点がないことを目安に次へ進む。これは教材内の自己評価基準。

進捗チェックリスト

  • 共通基礎の構成図と確認問題を完成した
  • AWSで権限・通信・監視・復旧を説明した
  • Azureで同じ要件を設計した
  • GCPで同じ要件を設計した
  • 三社の類似サービスと仕様差を比較した
  • Cloudflare・ニフクラを含む選定理由を説明した

参考資料は各教材の公式資料リンクを参照。
